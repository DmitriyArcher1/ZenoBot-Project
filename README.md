# 🧠 ZenoBot — Ваш личный органайзер задач в Telegram

> *«От хаоса к порядку: умное управление задачами с ZenoBot»*

ZenoBot — это мощный и интуитивно понятный Telegram-бот для создания, отслеживания и организации ваших задач. Забудьте о списках на стикерах — держите все дела под контролем прямо в мессенджере.

![Telegram](https://img.shields.io/badge/Telegram-ZenoBot-26A5E4?logo=telegram)

---

## ✨ Возможности (в разработке)

- ✅ **Создание задач** — быстро добавляйте задачи и управляйте ими.
- 📅 **Умные напоминания** — бот напомнит о важном в нужное время.
- 🏷️ **Категории и теги** — группируйте задачи по проектам (Работа, Личное, Учеба).
- 🔔 **Уведомления** — настраивайте периодические или одноразовые напоминания.
- 📊 **Статистика** — узнайте, сколько задач выполнено, просрочено или в работе.
- 🎨 **Интерактивные кнопки** — управление без изучения команд.

### Основные команды (в разработке)

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и главное меню |
| `/new` | Быстрое создание задачи |
| `/list` | Показать все активные задачи |
| `/today` | Задачи на сегодня |
| `/week` | План на неделю |
| `/done` | Отметить задачу выполненной |
| `/delete` | Удалить задачу |
| `/stats` | Ваша продуктивность в цифрах |
| `/help` | Помощь и инструкция |
